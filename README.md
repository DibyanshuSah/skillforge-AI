# SkillForge-AI

## 🌐 Live Demo

https://huggingface.co/spaces/rishusah/skillforge-ai

SkillForge-AI is an AI-powered learning assistant built using a local RAG (Retrieval-Augmented Generation) pipeline.  
The project focuses on generating context-aware responses from documents using semantic search and local LLM inference.

It combines vector search, embeddings, and local AI models to create a smarter and more efficient learning experience without depending completely on paid APIs.

## 🚀 Features

- Local RAG pipeline using Phi-3 GGUF
- FAISS-based vector search
- Semantic document retrieval
- Context-aware response generation
- Chunking and embedding-based retrieval
- Interactive Gradio interface
- Deployment on Hugging Face Spaces

## 🛠️ Technologies Used

- Python
- RAG
- Phi-3 GGUF
- FAISS
- Hugging Face
- Gradio
- NLP

## 📌 Project Objective

The main goal of this project was to explore how local LLMs and vector databases can work together to build efficient AI-powered educational tools with improved contextual understanding.

## ▶️ How to Run

1. Clone the repository

```bash
git clone <repository-link>
```

2. Open the project folder

```bash
cd skillforge-AI
```

3. Install dependencies

```bash
pip install -r requirements.txt
```

4. Run the application

```bash
python app.py
```
